# Security policy

AgentShield is an early-stage security testing project. Please do not submit real customer data, production secrets, or credentials in public issues.

## Authorized use only
Run scans only against systems you own or have explicit written authorization to assess. The scanner is intentionally read-only and limited to configured GET routes, but even read requests can access sensitive information if misconfigured.

## Reporting a vulnerability
For a vulnerability in this project, avoid publishing exploit details before maintainers have had a reasonable opportunity to investigate and fix it. This repository currently has no staffed security response team or guaranteed response SLA.
